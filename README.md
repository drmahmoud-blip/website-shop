# 🛍️ متجر لبسني | Labbesni Fashion Store & Admin Panel

متجر إلكتروني متكامل للأزياء مع لوحة تحكم إدارية وبوابة تسجيل دخول آمنة، متصل بالكامل بقاعدة بيانات **Supabase** السحابية.

---

## 🌟 الميزات الرئيسية

1. **بوابة المصادقة والأمان (`login.html`)**:
   - الدخول المباشر كمدير للنظام (`admin@lab.com` / `12345`) وفتح لوحة الإدارة.
   - التحقق من وجود المستخدمين في قاعدة بيانات Supabase قبل الدخول، أو تحويلهم لإنشاء حساب جديد.
   - حماية مشددة ضد حقن الأكواد وثغرات XSS و SQL Injection.

2. **متجر العملاء (`code_artifact (1).html` / `index.html`)**:
   - عرض فئات ومنتجات حية من Supabase.
   - تصفية فورية حسب الفئات، والأسعار، وبحث حي بالاسم.
   - سلة شراء تفاعلية مع حفظ الطلبات مباشرة في جدول `orders`.
   - نظام متابعة مراحل شراء وشحن الطلب لكل عميل (`Track Order`).

3. **لوحة تحكم الإدارة (`admin.html`)**:
   - تعديل فوري لأسعار المنتجات والمخزون والفئات.
   - رفع مباشر للصور من الجهاز وحفظها في **Supabase Storage**.
   - متابعة مراحل شراء كل عميل وتغيير حالتها بنقرة واحدة (قيد الانتظار ➔ جاري التجهيز ➔ تم الشحن ➔ تم التوصيل).
   - محادثة واتساب وتليجرام مباشرة مع العملاء.

---

## 🛠️ التقنيات المستخدمة
- HTML5, CSS3, Tailwind CSS (CDN), FontAwesome 6, Google Cairo Font.
- Vanilla JavaScript (ES6+).
- **Backend & Database:** Supabase (PostgreSQL, Storage, RLS Security).
- **Security:** Web Crypto API (SHA-256), Input Sanitization & Anti-Injection Guards.

---

## 🚀 التشغيل محلياً
يمكنك تشغيل المتجر عبر أي خادم محلي:
```bash
python -m http.server 3000
```
ثم فتح المتصفح على: `http://localhost:3000`
